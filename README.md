# 📖 About The Project

Managing an esports team becomes difficult when player information, team funds, strategies, and achievements are scattered across multiple platforms.

**Team Star Management System** brings everything together into one centralized web application, allowing administrators to efficiently organize team activities while providing members with a clean and user-friendly experience.

The project focuses on simplicity, organization, and efficient team management.

# Team Star Management System

A full-stack web application developed to help manage esports teams, resources, achievements, scrims, and financial records efficiently.

## Features

- User Authentication (Admin/User Login)
- Team Resource Management
- Achievement Gallery
- Scrim Management
- Strategy Management
- Profit & Loss Tracking
- CRUD Operations
- Dashboard Interface
- SQLite Database Integration

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Purpose

The project was built to simplify team operations by providing a centralized platform for managing resources, achievements, financial records, and competitive activities.
